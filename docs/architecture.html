Catalyst Components - Inventory Management

Full-stack demo: Vue 3 frontend, FastAPI backend, JSON files as in-memory data. No database.

System architecture

Frontend :3000

Vue 3 + Vite

  • 6 views routed by vue-router
  • Shared filter state (useFilters)
  • i18n for English and Japanese
  • Charts as custom SVG
→
Backend :8001

FastAPI

  • REST endpoints under /api
  • CORS middleware for the dev frontend
  • Filters applied in memory
  • Pydantic models validate responses
→
Data

JSON files

  • server/data/*.json
  • Loaded once by mock_data.py
  • 7 files: inventory, orders, demand, backlog, spending, transactions, purchase orders

Tech stack

Client

  • Vue 3 (Composition API)
  • vue-router 4
  • axios for HTTP
  • Vite as dev server and bundler

Server

  • Python 3.11 or newer
  • FastAPI with uvicorn
  • Pydantic 2
  • pytest with TestClient (tests in tests/backend)

Data flow

  1. The user changes a filter (time period, warehouse, category, order status).
  2. The view calls a method in client/src/api.js, which sends the filters as query parameters.
  3. FastAPI in server/main.py filters the in-memory lists loaded from JSON.
  4. Pydantic validates the result and the server returns JSON.
  5. The view stores the raw data in refs and derives the display values in computed properties.
